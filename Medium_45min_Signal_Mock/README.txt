Medium 45-minute Python signal-processing challenge
===================================================
1. Open Medium_45min_Signal_Decoder_CHALLENGE.ipynb in Jupyter or VS Code.
2. Run the embedded data cell first. The entire exercise works offline and does not require any extra packages.
3. Implement the three TODO functions and run the local judge.
4. Only then open Medium_45min_Signal_Decoder_SOLUTION.ipynb.
5. Optionally practice reading captured_signal.csv in the bonus section.

Scope: noisy carrier on/off detection + UART-style 8N1 frame decoding.
Assumptions: 8,000 samples/second, 400 bits/second, fixed aligned bit boundaries.
This is an invented mock, not the actual interview exercise.

Python standard library is all you need. Optional graphs use matplotlib if installed.
